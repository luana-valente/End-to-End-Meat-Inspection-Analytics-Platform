# Machine Learning Notebook

This folder contains the notebook developed for the Machine Learning workflow of the project.

The notebook covers:

- Exploratory data analysis.
- Feature engineering.
- Monthly data aggregation.
- Time-based train-test split.
- Regression model comparison.
- XGBoost optimization.
- Model evaluation.
- SHAP-based interpretation.

The workflow focuses on predicting sanitary condemnation rates using historical operational, temporal, geographic, and economic data.
