# Notebooks

This folder contains a curated selection of Microsoft Fabric notebooks developed for the data engineering workflows of the project.

The notebooks are organized according to the main processing stages of the solution:

- **Bronze:** raw data ingestion, metadata enrichment, incremental loading, and Delta table creation.
- **Silver:** data cleaning, deduplication, standardization, reconciliation, and data quality validation.
- **Gold:** dimensional modelling, fact and dimension table creation, SCD Type 2 logic, and preparation of business-ready datasets.

Only selected notebooks are included in this repository. The complete Microsoft Fabric workspace is not publicly available due to data confidentiality and project governance constraints.

All published notebooks were reviewed to remove confidential data, credentials, internal paths, and identifiable animal holding information.
